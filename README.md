# TaskTracker

Projeto acadêmico do Bootcamp II — Etapa Inicial.

## Sobre o projeto

O TaskTracker é uma proposta de sistema para organização e acompanhamento de tarefas pessoais, acadêmicas e profissionais. Nesta fase, o foco está no planejamento lógico, levantamento de regras, definição de entradas e saídas e preparação da arquitetura para as próximas etapas do Bootcamp.

## Objetivo

Centralizar tarefas em um único sistema, permitindo organizar atividades por prioridade, prazo e status, além de preparar uma base clara para futura implementação em Python e versionamento com Git/GitHub.
