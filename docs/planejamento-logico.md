# Planejamento Lógico — TaskTracker

## 1. Identificação e entendimento do problema

Muitas pessoas precisam acompanhar tarefas pessoais, acadêmicas e profissionais ao mesmo tempo. Quando esse controle é feito apenas por memória ou anotações dispersas, podem ocorrer esquecimentos, atrasos e perda de prioridade.

O TaskTracker será um sistema simples de gerenciamento de tarefas, pensado para centralizar esse controle e permitir acompanhamento claro do que precisa ser feito.

## 2. Solução proposta

O sistema permitirá cadastrar tarefas, definir prioridade e prazo, acompanhar status e marcar atividades como concluídas.

## 3. Entradas de dados

- Título da tarefa
- Descrição
- Prioridade
- Prazo
- Status

## 4. Saídas de dados

- Lista de tarefas cadastradas
- Situação de cada tarefa
- Prioridade
- Prazo
- Indicação de tarefa concluída ou pendente

## 5. Regras principais

- Toda tarefa deve possuir título.
- A prioridade deve seguir valores válidos definidos pelo sistema.
- O status deve indicar se a tarefa está pendente ou concluída.
- O prazo deve ser armazenado de forma consistente.
- Uma tarefa poderá ser atualizada ao longo do seu ciclo de vida.

## 6. Objetivo desta fase

Nesta etapa não será implementado o sistema completo. O foco é registrar a lógica, a arquitetura planejada e a organização do projeto para servir de base às próximas fases do Bootcamp.
