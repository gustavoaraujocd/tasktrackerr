# TaskTracker Mobile — Atividade de listas e formulários

Aplicação React Native criada com Expo. O projeto possui duas telas no `App.js`:

- **Inspirações:** uma imagem de capa, cinco itens com imagem, título e resumo; ao tocar em um item, uma descrição de pelo menos 30 palavras é exibida.
- **Planejador:** quatro inputs, dois Pickers, dois Sliders, dois Switches e dois botões com retorno visual.

## Como executar

```bash
cd mobile
npm install
npm start
```

Leia o QR Code com o Expo Go ou pressione `a`, `i` ou `w` para abrir no Android, iOS ou navegador.

## Validação dos requisitos

```bash
npm test
```

O teste confere automaticamente as quantidades mínimas exigidas, as duas telas e o total de palavras das descrições.
